# Консольный менеджер задач (To-Do)

**Цель продукта:** простая консольная программа, в которой пользователь добавляет, отмечает, ищет и удаляет задачи, а данные сохраняются между запусками.

Учебный проект для практической работы №9 «Управление проектом и командная работа».

Ревьюер: участники проверяют pull request’ы друг друга.

## Как запустить

Нужен Python 3.9+.

```bash
python todo.py add "Сдать практическую" --priority high --deadline 2026-11-05
python todo.py list
python todo.py done 1
python todo.py search практическ
python todo.py stats
python todo.py delete 1
```

Тесты:

```bash
python -m unittest -v
```

## Правила работы в Git

**Ветки**

- `main` — стабильная версия, прямые коммиты запрещены;
- `develop` — интеграция, сюда идут все pull request’ы;
- `feature/<номер-задачи>-<кратко>` — рабочие ветки, создаются от `develop`, например `feature/TASK-5-delete-task`.

**Коммиты.** Формат `префикс: описание (TASK-N)`. Префиксы: `feat`, `fix`, `docs`, `refactor`, `test`.
Пример: `feat: добавить функцию удаления задачи (TASK-5)`.

**Pull request.** В описании ссылка на задачу и что именно сделано. Слияние только после одобрения второго участника (минимум один комментарий в ревью).

**Доска.** To Do → In Progress → Code Review → Done. WIP-limit: не более 2 задач в работе на человека.
